# Xdownload2 사용 안내

유튜브 영상·음원을 받고, 내 컴퓨터의 동영상·이미지를 다른 형식으로 바꾸는 Windows 프로그램입니다.
설치가 필요 없습니다. `xdownload2.exe` 하나를 받아 실행하면 됩니다. (Windows 10 / 11, 64비트)

## 처음 실행할 때

### "Windows의 PC 보호" 창이 뜨면
이 프로그램에는 아직 코드 서명이 없어서 Windows 가 경고를 보여 줍니다.
**추가 정보** 를 누른 다음 **실행** 을 누르면 됩니다.

### 처음 한 번은 준비 시간이 필요합니다
처음 실행하면 다운로드에 쓰는 도구 두 개(yt-dlp, ffmpeg, 합쳐서 약 200MB)를 자동으로 받습니다.
창 아래에 "준비 중 ... %" 가 보이고, 끝나면 "준비됨" 으로 바뀝니다. 다음부터는 바로 시작됩니다.
인터넷이 연결되어 있어야 합니다.

## 다운로드

1. 유튜브 링크를 입력칸에 붙여 넣습니다. 여러 개는 한 줄에 하나씩 넣습니다.
   링크를 복사한 뒤 이 창으로 돌아오면 자동으로 들어갑니다(설정에서 끌 수 있습니다).
2. 형식을 고릅니다.
   - **MP4**: 영상. 화질은 최고 / 4K / 1440p / 1080p / 720p / 480p.
   - **MP3**: 음원. 어디서나 재생됩니다.
   - **M4A**: 음원. 유튜브 원본 음질 그대로입니다.
3. 필요하면 켭니다: 자막 넣기, 썸네일·정보 넣기, 플레이리스트 전체.
4. **다운로드** 를 누릅니다(입력칸 밖에서는 Enter).

아래 작업 목록에 진행 상황이 나옵니다. 한 번에 3개씩 받습니다(설정에서 1~5개).
항목 오른쪽의 ✕ 로 취소하고, 실패한 항목은 ↻ 로 다시 시도합니다. Esc 는 전부 취소합니다.

> 1080p 까지는 어느 기기에서나 재생되는 형식(H.264)으로 받습니다.
> 4K·1440p 는 유튜브가 다른 형식으로만 제공해서, 오래된 기기에서는 재생되지 않을 수 있습니다.

## 변환

**변환** 탭에서 형식을 고르고 **파일 선택** 이나 **폴더 선택** 을 누릅니다.
파일이나 폴더를 창에 끌어다 놓아도 됩니다.

- 동영상 → MP4(크기와 화질 선택) / MP3(소리만) / GIF(앞 30초)
- 이미지 → JPG / PNG / WebP

원본은 그대로 두고 같은 폴더에 새 파일을 만듭니다. 같은 이름이 있으면 `-2`, `-3` 을 붙입니다.
그래픽카드가 있으면 동영상 변환에 자동으로 씁니다(설정에서 끌 수 있습니다).

## 기록 · 설정

- **기록**: 받은 파일 목록입니다. 두 번 클릭하면 파일을 엽니다. 오른쪽 단추로 폴더 열기, 다시 받기, 지우기.
- **설정**: 동시에 받는 개수, 그래픽카드 변환, 링크 자동으로 넣기, 다 받으면 폴더 열기.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| "준비 실패" | 인터넷 연결을 확인하고 다시 다운로드를 누릅니다. 회사·학교 네트워크는 github.com 접속을 막을 수 있습니다. |
| 특정 영상만 실패 | 비공개·연령 제한·지역 제한 영상은 받을 수 없습니다. |
| 갑자기 모든 영상이 실패 | 유튜브가 바뀐 경우입니다. 프로그램이 도구를 자동으로 업데이트한 뒤 한 번 더 시도합니다. 그래도 안 되면 다음 날 다시 실행해 보세요. |
| 모든 작업이 실패 | 설정 탭의 **yt-dlp·ffmpeg 다시 받기**(↻)를 누른 뒤 다시 시도합니다. |
| 프로그램이 꺼짐 | `%APPDATA%\Xdownload2\logs\crash.log` 파일을 보내 주세요. |

## 데이터 위치와 지우는 법

프로그램은 `%APPDATA%\Xdownload2` 폴더만 씁니다(설정 탭의 **데이터 폴더 열기**).
설정, 기록, 받아 둔 도구가 여기에 있습니다. 레지스트리나 다른 곳은 건드리지 않습니다.

지우려면 `xdownload2.exe` 와 이 폴더를 삭제하면 됩니다.
